# Product Atlas Admin Guide

## User Roles
Atlas supports Viewer, Editor, Admin, and Owner roles. Viewers can read dashboards, Editors can modify workspace content, Admins can manage integrations, and Owners can control billing and workspace deletion.

## Data Import
CSV imports support up to 250 MB per file. Imports above 50 MB run asynchronously and send completion notifications to workspace admins.

## Audit Log
The audit log records login events, permission changes, integration updates, export jobs, and failed authentication attempts. Audit records are retained for 18 months on the Enterprise plan.
